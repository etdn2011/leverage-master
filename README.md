# leverage-master · 杠杆大师

> 给一个提案，找到杠杆点，给出关键动作。

---

## 一句话定位

**基于IPO模型（Input-Process-Output），通过第一性原理×系统思考×人性三维分析，匹配专家视角，输出可执行的关键判断和行动方案。**

不是讨论问题，是找到杠杆点、给出关键动作。

---

## 核心理念

**不是给你一份计划，而是告诉你该做什么——或者不该做什么。**

- **加法思维**（传统执行模式）：拆分任务 → 分工 → 排时间 → 输出清单
- **杠杆思维**（本系统）：还原问题 → 找到杠杆点 → 一个关键动作 → 其他事变容易或不再需要

---

## 系统架构（IPO模型）

```
用户输入提案（可能模糊）
    ↓
[Layer 1] Input澄清层
    - 动态追问，不设固定模板，最多2轮
    - 只追问对「定义问题」有决定性影响的信息
    - 输出：清晰的问题陈述
    ↓
[Layer 2] Process路由层
    - 匹配专家（≥80%直接调用，<80%异步蒸馏）
    - 默认单专家，用户可追加团队或换专家
    - 女娲方法论仅作参考，不直接继承
    ↓
[Layer 3] Process解决层（IPO三维分析）
    - 专家以直接输出者身份，用三维框架分析：
      ├── 第一性原理：还原问题本质
      ├── 系统思考：找到杠杆点
      └── 人性：内外部行为动机和认知偏差
    - 输出4样东西（落到执行层面）
    ↓
[Layer 4] Output回路层（最多1次）
    - 如果「真正的问题」和「澄清后的问题」不一致
    - 回到用户确认 → 重新走Layer 2-3
    ↓
输出标准版 + 提示可深入方向
```

## 三维分析框架

### 维度1：第一性原理

**目的**：剥离所有假设，找到问题的物理/商业本质。

```
专家视角切入：
1. 用户的提案基于什么假设？
2. 这些假设成立吗？（用专家的独特视角质疑）
3. 剥离假设后，不可改变的基本事实是什么？
4. 从基本事实出发，问题应该怎么重新定义？
```

### 维度2：系统思考

**目的**：找到系统的杠杆点，用最小干预产生最大效果。

```
1. 这个提案涉及的系统是什么？（画出系统边界）
2. 核心变量和因果关系是什么？
3. 反馈回路在哪里？（正反馈/负反馈/延迟）
4. 约束/瓶颈在哪里？（Theory of Constraints）
5. 最高杠杆的干预点是什么？（Meadows 12个杠杆点）
```

### 维度3：人性

**目的**：确保方案在人的层面可执行。

```
外部人性（用户/消费者/市场侧）：
1. 这个方案涉及的用户，他们的真实动机是什么？
2. 他们的认知偏差是什么？（损失厌恶/从众/锚定...）
3. 什么会触发他们的行为改变？
4. 什么会让他们抗拒？

内部人性（执行者/团队侧）：
1. 提案者/执行团队自身的认知盲区在哪里？
2. 团队的动机冲突是什么？（个人利益 vs 组织目标）
3. 执行过程中最容易因为人性而失败的是哪一步？
4. 如何设计执行机制来对抗这些人性的弱点？
```

**三维交叉验证**：三个维度的结论必须互相支撑，不能矛盾。

```bash
git clone https://github.com/etdn2011/leverage-master.git
```

### 使用

**触发词**：
- 「杠杆」
- 「帮我分析这个提案」
- 「给我一个方案」
- 「用XX的视角看这个问题」

**追加指令**：
- 「再听听XX的看法」 → 切换专家重新分析
- 「用团队来看」 → 组建多专家团队
- 「深入[维度]」 → 展开某个维度的详细分析
- 「深入执行」 → 把关键动作拆成详细执行计划

## 贡献指南

### 添加新专家

1. 在 `experts/` 下创建新文件夹
2. 使用 `templates/expert-profile-template.md` 编写PROFILE
3. 使用 `templates/case-template.md` 记录案例（至少3个）
4. 更新 `EXPERTS-LIST.md`
5. 提交PR

### 添加新案例

1. 在对应专家的 `cases/` 下创建新文件
2. 使用 `templates/case-template.md` 格式
3. 更新PROFILE中的案例索引
4. 提交PR

## 核心理念速查

| 原则 | 一句话 |
|------|--------|
| 杠杆思维 | 找到杠杆点，一个关键动作，其他事变容易或不再需要 |
| 第一性原理 | 剥离假设，还原到基本事实，重新定义问题 |
| 系统思考 | 找到约束节点，在约束节点上投入1份力 = 非约束节点上10份力 |
| 人性 | 方案在纸面上完美，在人的层面可能完全不可执行 |
| 案例锚定 | 每个判断都有案例支撑，不是通用分析 |
