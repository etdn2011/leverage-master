# 案例：ofo 的教训

> 朱啸虎的反思之作——共享单车风口中，赛道判断正确但商业模式未验证就大规模烧钱，最终以失败告终。这个案例深刻揭示了「烧钱换规模」策略的边界条件。

---

## 一、背景

### 1.1 投资概览

| 维度 | 详情 |
|------|------|
| **投资机构** | 金沙江创投（GSR Ventures） |
| **投资人** | 朱啸虎（主导） |
| **投资时间** | 2015-2016 年 |
| **投资轮次** | A 轮 / 早期 |
| **被投企业** | ofo 小黄车 |
| **创始人** | 戴威（北京大学学生创业团队） |
| **最终结果** | ofo 资金链断裂，2018-2019 年走向衰败，最终被收购/清算，投资大幅亏损 |

### 1.2 时代背景

2015-2016 年的中国共享经济风口：
- 「共享经济」成为最热门的投资主题，资本大量涌入
- 摩拜单车和 ofo 几乎同时出现，共享单车赛道迅速升温
- 城市短途出行（最后一公里）存在真实需求——地铁到公司/学校的「最后一公里」缺乏好的解决方案
- 智能手机 + 移动支付 + GPS 定位的技术基础设施已成熟
- 资本市场极度宽松，大量资金追逐「风口」项目
- 创投圈弥漫着「风口上猪都能飞」的氛围

### 1.3 创始人背景

戴威，北京大学学生，与几位同学一起创办 ofo。团队年轻、充满理想主义色彩，但在企业管理、财务控制、战略规划等方面经验严重不足。ofo 最初是北大校园内的自行车共享项目，后迅速扩张至全国。

---

## 二、IPO 三维分析

### 2.1 第一性原理（商业本质）

**核心问题：共享单车是真实需求还是伪需求？**

朱啸虎当时的分析（投资时）：
- **需求真实性**：城市「最后一公里」出行确实存在痛点，共享单车提供了一种便捷的解决方案
- **使用频率**：通勤场景高频，看起来是一个好生意
- **商业模式**：用户付费骑行 + 押金资金池 + 广告收入
- **可规模化**：单车投放可以快速复制到各个城市

**事后反思的盲区**：
- **单位经济模型不成立**：单车的制造成本、运维成本、损坏率远超预期，每次骑行的收入无法覆盖成本
- **押金模式的脆弱性**：押金资金池虽然提供了现金流，但本质上不是可持续的商业模式，且存在合规风险
- **无桩模式的代价**：ofo 的无桩模式虽然用户体验好，但带来了巨大的运维成本和管理难题——车辆损坏、乱停乱放、被盗严重
- **需求 vs 愿付价格**：用户确实有需求，但愿意为单次骑行支付的价格极低，难以覆盖成本

**教训**：需求真实不等于商业模式成立。必须验证单位经济模型，而不仅仅是验证需求存在。

### 2.2 系统思考（生态格局）

**朱啸虎当时的分析（投资时）**：
- 赛道处于爆发早期，竞争格局未定
- ofo 和摩拜是两大主要玩家，窗口期有限
- 必须快速烧钱抢占市场份额，建立规模优势

**事后反思的盲区**：
- **忽视了「烧钱换规模」的前提条件**：烧钱换规模的前提是商业模式成立（单位经济模型为正）且窗口期真实存在。共享单车的商业模式从未真正成立，烧钱只是在加速消耗资金
- **低估了运维复杂度**：共享单车不是一个纯线上的互联网生意，它有极强的线下属性——车辆调度、维修、管理。这些线下运营的复杂度和成本被严重低估
- **高估了竞争壁垒**：共享单车的壁垒并不高——任何人只要有资金就可以投放单车。所谓的「规模优势」并没有转化为真正的竞争壁垒
- **忽视了政策风险**：城市管理部门对共享单车的态度从初期的默许到后期的严格管控，政策环境的变化对行业产生了致命影响

**教训**：系统思考不能只看「竞争格局」和「窗口期」，还要看商业模式的可持续性、线下运营的复杂度、以及政策环境的变化。

### 2.3 人性（创业者与用户）

**创业者维度（投资时的判断）**：
- 戴威年轻、有野心、执行力强，在北大校园内成功启动了项目
- 展现出快速扩张的欲望和能力

**创业者维度（事后反思）**：
- **管理能力严重不足**：戴威和团队缺乏管理大规模企业和复杂供应链的经验。随着 ofo 快速扩张，管理失控问题日益严重
- **财务纪律缺失**：在大量资金涌入后，团队在花钱上缺乏节制，大量资金浪费在无效投放和内部管理上
- **战略判断失误**：面对与摩拜的竞争，戴威选择了继续烧钱扩张而非寻求合并或盈利，最终导致资金链断裂
- **理想主义的陷阱**：戴威过于理想化，不愿意接受合并方案，错过了多次与摩拜合并的机会

**用户维度**：
- 用户确实享受了共享单车带来的便利
- 但用户的忠诚度极低——谁家车好用、谁家便宜就用谁家
- 押金退还问题引发了大量用户投诉，损害了行业声誉

**教训**：创业者的「野心」和「执行力」必须与「管理能力」和「财务纪律」匹配。没有管理能力支撑的野心，只会加速毁灭。

## 三、核心策略

### 3.1 风口判断

朱啸虎判断共享单车是 2015-2016 年最大的风口之一：
- 「最后一公里」出行需求真实存在
- 技术基础设施（智能手机、移动支付、GPS）已成熟
- 资本市场对「共享经济」主题极度追捧
- ofo 和摩拜的出现标志着赛道进入爆发期

**事后反思**：风口判断本身没有错，但「风口」不等于「好投资」。风口中同样有大量泡沫和陷阱。

### 3.2 烧钱换规模

与滴滴案例类似，朱啸虎支持 ofo 大规模烧钱抢占市场：
- 快速投放大量单车到各个城市
- 通过免费骑行、红包等补贴获取用户
- 与摩拜展开烧钱竞赛，争夺市场份额

**事后反思**：这是最大的失误。滴滴的烧钱换规模之所以成功，是因为滴滴的商业模式成立（抽佣模式，单位经济模型为正）。而 ofo 的商业模式从未成立，烧钱只是在加速死亡。

### 3.3 管理失控

随着 ofo 快速扩张，管理问题全面爆发：
- 车辆损坏率极高，维修跟不上
- 供应链管理混乱，单车质量参差不齐
- 财务管理失控，资金使用效率极低
- 团队内部派系斗争严重
- 创始人戴威在战略决策上反复无常

**事后反思**：朱啸虎在投资后未能有效帮助 ofo 建立管理体系。作为早期投资人，不仅需要提供资金，还需要在被投企业的管理升级中发挥积极作用。

## 四、关键动作

| 时间 | 动作 | 意义 |
|------|------|------|
| 2015 年 | ofo 在北大校园内启动 | 校园市场切入，验证需求 |
| 2016 年 | 金沙江创投 A 轮投资 ofo | 风口判断落地，进入共享单车赛道 |
| 2016-2017 年 | 支持ofo大规模烧钱扩张 | 烧钱换规模策略启动 |
| 2017 年 | ofo 与摩拜的烧钱竞赛白热化 | 两家合计烧掉数十亿美元 |
| 2017 年 | 多次推动 ofo 与摩拜合并谈判 | 尝试止损，但戴威拒绝合并 |
| 2018 年 | ofo 资金链断裂，大规模裁员退押金危机 | 烧钱换规模策略失败 |
| 2018-2019 年 | ofo 走向衰败，最终被收购/清算 | 投资失败 |

## 五、结果与复盘

### 5.1 结果

- **财务损失**：金沙江创投在 ofo 上的投资大幅亏损，与滴滴的千倍回报形成鲜明对比
- **声誉影响**：虽然朱啸虎在滴滴和饿了么上的成功足以支撑其行业地位，但 ofo 的失败仍然是一个明显的污点
- **方法论反思**：ofo 的失败促使朱啸虎公开反思「烧钱换规模」策略的边界条件，对其后续投资风格产生了深远影响

### 5.2 复盘

**做错了什么**：
1. **商业模式未验证就大规模烧钱**：这是最核心的失误。在 ofo 的单位经济模型尚未验证的情况下，就支持大规模烧钱扩张。滴滴的「烧钱换规模」成功经验被错误地套用到了一个商业模式不成立的项目上
2. **低估了线下运营的复杂度**：共享单车不是纯互联网生意，线下运维的复杂度和成本被严重低估
3. **忽视了对创业者管理能力的评估**：戴威有野心和执行力，但缺乏管理大规模企业的能力。投资人未能及时识别和弥补这一缺陷
4. **未能及时止损**：在 ofo 管理失控的信号已经很明显时，未能推动有效的干预措施（如更换 CEO、强制合并等）
5. **被风口情绪裹挟**：「共享经济」风口的热度影响了判断的客观性，在应该更谨慎的时候选择了更激进

**有什么值得肯定的**：
1. 风口判断本身没有错——共享单车确实是一个巨大的市场机会
2. 在后期积极推动 ofo 与摩拜合并，试图止损
3. 事后公开反思，没有回避失败，展现了投资人的诚实和担当

## 六、专家思维还原

### 6.1 朱啸虎在投资 ofo 时的思维过程（还原）

**第一步：风口判断（当时的思维）**
> 「2015 年，共享单车赛道正在爆发。最后一公里出行是真实需求，技术基础设施已成熟。这个风口不能错过。」

**第二步：创业者评估（当时的思维）**
> 「戴威在北大校园里把 ofo 做起来了，说明他有执行力。他有野心，想把 ofo 做成全球最大的共享单车平台。年轻团队，敢打敢拼。」

**第三步：策略选择（当时的思维）**
> 「赛道爆发了，必须快速烧钱抢占市场。滴滴就是这么赢的——先烧钱拿市场份额，格局定了再赚钱。ofo 也应该这么做。」

**第四步：事后反思（现在的思维）**
> 「我们犯了一个根本性的错误——在商业模式没有验证的情况下就大规模烧钱。滴滴的商业模式是成立的（抽佣），但 ofo 的单位经济模型从来没有成立过。每骑一次车都在亏钱，车还在不断损坏。烧钱换规模的前提是商业模式成立，这个前提我们忽略了。」

> 「戴威是个有野心的年轻人，但他没有管理好一家快速扩张的公司的能力。我们太早把他推上了那个位置。」

> 「共享单车不是纯互联网生意，它有极强的线下属性。车辆损坏、调度、维修——这些线下运营的复杂度和成本，我们严重低估了。」

### 6.2 体现的心智模型

| 心智模型 | 在此案例中的体现 | 反思 |
|---------|----------------|------|
| 赛道优先 | 判断共享单车赛道处于风口 | 赛道判断正确，但赛道正确不等于投资正确 |
| 20%法则 | 判断共享单车渗透率接近拐点 | 拐点判断基本正确，但忽略了商业模式验证 |
| 烧钱换规模 | 支持ofo大规模烧钱扩张 | **此模型在此案例中失效**——商业模式不成立时，烧钱加速死亡 |
| 创业者特质 | 看重戴威的野心和执行力 | **忽略了管理能力**——野心和执行力不等于管理能力 |
| 快速决策 | 在风口中果断出手 | 快速决策在赛道判断正确时是优势，但在商业模式未验证时是风险 |

### 6.3 关键启示

1. **烧钱换规模有前提条件**：商业模式必须成立（单位经济模型为正），赛道窗口期必须真实存在。如果前提条件不满足，烧钱只会加速死亡
2. **需求真实不等于商业模式成立**：共享单车的需求是真实的，但每骑一次都在亏钱。投资人不仅要验证需求，还要验证单位经济模型
3. **线下生意的复杂度不能低估**：不是所有「互联网+」生意都是纯线上的。线下运营的复杂度和成本必须被充分评估
4. **创业者的管理能力是关键变量**：野心和执行力在早期足够，但企业规模扩大后，管理能力成为生死变量。投资人必须评估创业者是否有成长为新 CEO 的潜力
5. **及时止损比坚持更重要**：当信号表明方向错误时，及时止损比坚持到底更明智。ofo 多次有机会与摩拜合并，但被创始人拒绝，投资人未能有效推动
6. **风口中的冷静比热情更珍贵**：在所有人都疯狂的时候保持冷静，可能是投资人最重要的品质
