# 案例：投资饿了么

> 朱啸虎的早期经典——25 万美元起步，以校园市场为切入点，用最小成本验证需求，再逐步扩张。这是「赛道优先 + 低烧钱验证 + 区域扩张」的教科书级案例。

---

## 一、背景

### 1.1 投资概览

| 维度 | 详情 |
|------|------|
| **投资机构** | 金沙江创投（GSR Ventures） |
| **投资人** | 朱啸虎（主导） |
| **投资时间** | 2008 年（天使/早期） |
| **投资金额** | 首期约 25 万美元，后续追加至约 100 万美元 |
| **投资阶段** | 天使轮 / 早期 |
| **被投企业** | 饿了么（Ele.me） |
| **创始人** | 张旭豪（上海交通大学学生创业团队） |
| **最终结果** | 2017 年饿了么以约 95 亿美元被阿里巴巴收购，金沙江获得丰厚回报 |

### 1.2 时代背景

2008 年的中国互联网环境：
- PC 互联网仍是主流，移动互联网尚未爆发
- 高校学生群体是互联网服务的早期 adopter
- 外卖需求在高校场景中天然存在且高频——学生懒得出门、食堂选择有限、宿舍不能做饭
- 当时外卖市场以电话订餐为主，效率低下，信息极度不透明
- O2O（Online to Offline）概念尚未流行，但本地生活服务的线上化趋势已初现端倪

### 1.3 创始人背景

张旭豪，上海交通大学在读研究生，与几位同学一起在宿舍创办饿了么。团队年轻、缺乏商业经验，但充满创业热情。最初的「产品」非常简陋——一个简单的网页，展示学校周边餐厅的菜单和电话。

---

## 二、IPO 三维分析

### 2.1 第一性原理（商业本质）

**核心问题：高校外卖是真实需求还是伪需求？**

朱啸虎的分析逻辑：
- **需求真实性**：高校学生对外卖的需求极其真实——宿舍环境限制、食堂选择有限、学习忙碌、追求便利。这不是「创造出来的需求」，而是「把已有需求线上化」
- **需求高频**：一日三餐，外卖是刚需且高频的消费场景
- **市场规模**：全国高校学生数千万，每人每月外卖消费数百元，市场空间可观
- **商业模式**：平台模式，连接学生和餐厅，从订单中抽佣。轻资产，可规模化
- **可验证性**：可以在单个高校用极低成本验证需求，不需要大规模投入

**结论**：需求真实、高频、可低成本验证，是一个值得尝试的早期投资标的。

### 2.2 系统思考（生态格局）

**核心问题：这个赛道会如何演化？**

朱啸虎的分析逻辑：
- **切入点选择**：高校是一个封闭、密集、用户行为高度一致的「天然实验室」，适合做 MVP 验证
- **扩张路径**：单个高校 → 上海高校群 → 京沪高校 → 全国高校 → 城市白领市场。路径清晰，每一步都可以用前一步的成果来融资
- **竞争格局**：2008 年外卖 O2O 赛道几乎没有竞争对手，先发优势明显
- **关键壁垒**：餐厅资源（供给端）和用户习惯（需求端）的双边网络效应
- **风险因素**：美团等本地生活巨头未来可能进入，但短期内高校市场的深耕可以建立壁垒

**结论**：赛道早期、竞争空白、扩张路径清晰，适合早期投资。

### 2.3 人性（创业者与用户）

**创业者维度**：
- 张旭豪和团队虽然年轻且缺乏经验，但展现出极强的**地面执行力**——能一家一家餐厅去谈合作，能一个一个宿舍去推广
- 展现出**学习能力**——从简陋的网页开始，不断迭代产品和技术
- 展现出**野心**——不满足于做交大校园的外卖，要做全上海、全国的外卖平台
- 朱啸虎判断：年轻团队有不足，但核心驱动力足够

**用户维度**：
- 高校学生的核心需求：不想出门、食堂不好吃、选择少、想要便宜
- 餐厅的核心需求：增加订单量、减少闲置产能、获取年轻客群
- 两端都有明确痛点，平台撮合的价值清晰

**结论**：创业者虽然年轻但执行力强，两端用户需求明确，可以在小范围快速验证。

---

## 三、核心策略

### 3.1 校园市场切入

朱啸虎支持饿了么从上海交通大学单一校园开始：
- **封闭场景**：高校是一个相对封闭的环境，用户集中、需求统一、推广成本低
- **快速验证**：在一个校园内用极低成本验证「学生是否愿意在线点外卖」这个核心假设
- **口碑传播**：高校学生社交密集，好的产品可以快速通过口碑传播
- **低风险试错**：如果模式不成立，损失有限；如果成立，扩张路径清晰

### 3.2 低烧钱验证

与滴滴的「大规模烧钱」策略不同，饿了么早期采取了「低烧钱验证」策略：
- 首期投入仅 25 万美元，用最小成本验证需求
- 不做大规模补贴，而是靠产品体验和口碑获取用户
- 在单个高校跑通模型后，再追加投资扩张到更多高校
- 100 万美元站稳上海和北京高校市场，每一分钱都花在刀刃上

### 3.3 区域扩张

验证成功后，饿了么按照清晰的区域扩张路径推进：
- 上海高校群 → 北京高校 → 全国重点城市高校 → 城市白领市场
- 每进入一个新城市/区域，都先做小范围验证，再大规模推广
- 逐步建立餐厅供给网络和用户基础，形成区域壁垒

## 四、关键动作

| 时间 | 动作 | 意义 |
|------|------|------|
| 2008 年 | 金沙江创投天使投资饿了么约 25 万美元 | 赛道判断落地，最小成本验证 |
| 2008-2009 年 | 支持饿了么在上海交大校园验证模式 | 校园市场切入，验证需求真实性 |
| 2009-2010 年 | 追加投资至约 100 万美元 | 验证成功后加注，扩张至上海和北京高校 |
| 2010-2013 年 | 支持饿了么逐步扩张至全国高校市场 | 区域扩张策略落地 |
| 2013-2015 年 | 饿了么从高校走向城市白领市场 | 市场天花板打开，进入高速增长期 |
| 2017 年 | 饿了么被阿里巴巴以约 95 亿美元收购 | 金沙江获得丰厚退出回报 |

## 五、结果与复盘

### 5.1 结果

- **财务回报**：25 万美元起步，最终饿了么以约 95 亿美元被阿里巴巴收购，金沙江创投获得极高回报倍数
- **行业影响**：验证了「校园切入 → 区域扩张 → 全市场覆盖」的 O2O 扩张路径，成为后续众多本地生活服务创业者的参考范本
- **方法论沉淀**：与滴滴的「烧钱换规模」形成互补——证明了在赛道早期阶段，「低烧钱验证」同样是有效的投资策略

### 5.2 复盘

**做对了什么**：
1. **赛道判断前瞻**：在 2008 年外卖 O2O 概念尚未流行时就看到了这个赛道的潜力
2. **切入点精准**：选择高校作为切入点，用最小成本验证需求，降低了早期投资风险
3. **投资节奏合理**：25 万美元试水 → 100 万美元站稳 → 后续融资扩张，节奏把控精准
4. **创业者识别准确**：在张旭豪还是在校大学生时就看到了其执行力和野心
5. **扩张路径清晰**：校园 → 城市 → 全市场的扩张路径，每一步都有前一步的验证支撑

**有什么遗憾或可改进之处**：
1. 早期投资金额偏小，如果更大胆地投入，份额占比会更高
2. 在饿了么与美团外卖的竞争中，未能帮助饿了么建立更深的竞争壁垒

## 六、专家思维还原

### 6.1 朱啸虎在投资饿了么时的思维过程（还原）

**第一步：赛道扫描**
> 「2008 年，高校学生的外卖需求是真实存在的，但没有人用互联网的方式去满足它。电话订餐效率太低了。如果有一个平台能把学生和餐厅连接起来，这个需求是可以被线上化的。」

**第二步：切入点判断**
> 「高校是最好的切入点。学生集中、需求统一、推广成本低。先在一个学校验证，如果行得通，复制到其他学校。如果不行，25 万美元的损失也承受得起。」

**第三步：创业者评估**
> 「张旭豪还是个学生，没什么经验。但他能在宿舍里把这件事做起来，说明他有执行力。他不是只想做交大的外卖，他想做全中国的外卖平台，这说明他有野心。年轻人不怕没经验，怕的是没野心、不肯学。」

**第四步：投资节奏**
> 「先给 25 万，让他们在一个学校跑通模型。跑通了再追加。不要一开始就给太多钱，太多钱反而会让团队不专注。」

### 6.2 体现的心智模型

| 心智模型 | 在此案例中的体现 |
|---------|----------------|
| 赛道优先 | 先判断外卖 O2O 赛道的潜力，再评估张旭豪团队 |
| 20%法则 | 判断高校学生对外卖的接受度已接近拐点 |
| 创业者特质 | 看重张旭豪的执行力（地推餐厅）和野心（全国平台） |
| 快速决策 | 在赛道早期、竞争空白时果断出手 |
| 烧钱换规模（变体） | 此案例中体现为「低烧钱验证」——先用最小成本验证，再逐步加大投入 |

### 6.3 关键启示

1. **早期投资不一定要大钱**：25 万美元的天使投资，同样可以成就百亿美元级的退出。关键在于赛道和创业者是否正确
2. **切入点决定验证成本**：选择高校作为切入点，让饿了么可以用极低成本验证需求。好的切入点可以大幅降低早期投资风险
3. **投资节奏比金额更重要**：先小规模验证，再逐步加注。不要一开始就给太多钱，太多钱反而会让团队失去紧迫感
4. **年轻创业者不可小觑**：张旭豪还是学生时就展现出极强的执行力和野心。投资人要能识别潜力，而非只看履历
