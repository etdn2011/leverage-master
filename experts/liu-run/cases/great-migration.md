# 案例：大迁徙模型

> 专家：刘润
> 案例类型：增长策略 / 存量市场增量挖掘
> 蒸馏时间：2026-06-04

---

## 背景

2025年，刘润在奥维云网演讲《大迁徙——新的增长在哪里》中提出"大迁徙"模型。当时中国经济进入存量时代，很多企业面临增长停滞的困境。

**问题定义**：
- 存量市场内卷严重，价格战不断
- 传统增长方式（砸广告、铺渠道）效果递减
- 企业需要找到新的增长路径

---

## IPO三维分析

### Input（输入）

**问题边界**：
- 范围：存量市场的增长策略
- 目标：找到不依赖传统增长方式的新路径
- 约束：资源有限，不能盲目试错

**关键信息**：
- 中国GDP增速放缓，多数行业进入存量竞争
- 消费者需求正在发生结构性变化
- 技术变革（AI、新能源等）创造新的可能性

---

### Process（处理）

**第一性原理应用**：

1. **追问增长本质**：
   - 增长不是做更多同样的事
   - 增长是找到"正在流动的机会"
   - 就像河流，水一直在流，关键是找到水流的方向

2. **追问迁徙类型**：
   - 需求迁徙：人们的需求正在从哪里迁向哪里？
   - 情绪迁徙：人们的情绪重心正在从哪里迁向哪里？
   - 能力迁徙：技术/能力正在从哪里迁向哪里？

3. **追问底层规律**：
   - 经济周期：繁荣→衰退→复苏→增长
   - 技术周期：导入→成长→成熟→衰退
   - 需求周期：基本需求→品质需求→个性需求→意义需求

**系统思考应用**：

大迁徙的三维框架：

```
         需求迁徙
        /        \
       /          \
  情绪迁徙 ———— 能力迁徙
```

**需求迁徙**：
- 从"拥有"到"体验"
- 从"功能"到"情绪"
- 从"标准化"到"个性化"
- 从"消费"到"意义"

**情绪迁徙**：
- 从"焦虑"到"疗愈"
- 从"攀比"到"自洽"
- 从"外求"到"内观"
- 从"快节奏"到"慢生活"

**能力迁徙**：
- 从"人工"到"智能"
- 从"本地"到"全球"
- 从"封闭"到"开放"
- 从"重资产"到"轻资产"

**关键杠杆点**：
- 需求识别（Meadows第3层：系统目标）—— 找到正在迁徙的需求
- 情绪触发（Meadows第4层：规则）—— 顺应情绪迁徙设计产品
- 能力嫁接（Meadows第5层：信息流）—— 用新技术满足新需求

**人性应用**：

外部（消费者）：
- 损失厌恶：人们害怕错过正在发生的趋势
- 社会认同：迁徙具有传染性，看到别人迁，自己也想迁
- 即时满足：新需求往往承诺更快、更好的体验
- 自我实现：高层次需求（意义、自我表达）驱动迁徙

内部（企业）：
- 路径依赖：习惯了旧的增长方式，难以转型
- 沉没成本：已有的投入成为转型的阻力
- 恐惧未知：对迁徙方向的不确定性产生恐惧

---

### Output（输出）

**核心策略**：

不跟存量竞争，而是找到"正在迁徙"的需求、情绪和能力，提前布局，顺势而为。

**关键动作**：

1. **需求迁徙识别**：
   - 观察：消费者正在放弃什么？正在拥抱什么？
   - 分析：背后的驱动力是什么？（技术、人口、文化）
   - 判断：这是短期 fad 还是长期 trend？

2. **情绪迁徙顺应**：
   - 识别：目标人群的情绪重心正在迁向哪里？
   - 设计：产品如何顺应这种情绪？
   - 验证：情绪共鸣是否真实？

3. **能力迁徙嫁接**：
   - 盘点：新技术/新能力能解决什么旧问题？
   - 匹配：能力与需求的匹配点在哪里？
   - 落地：如何低成本验证？

4. **迁徙路径设计**：
   - 起点：现在的位置（存量业务）
   - 路径：迁徙的方向和步骤
   - 终点：新的增长空间

**执行计划**：

| 阶段 | 动作 | 产出 |
|------|------|------|
| 观察 | 三维迁徙扫描 | 迁徙机会地图 |
| 判断 | 趋势验证 | 高置信度迁徙方向 |
| 试点 | 小规模验证 | MVP验证报告 |
| 放大 | 资源投入 | 增长飞轮启动 |
| 迭代 | 持续跟踪迁徙 | 动态调整策略 |

**预期结果**：
- 短期：找到1-2个可验证的迁徙方向
- 中期：在迁徙方向上建立先发优势
- 长期：成为新需求/新情绪/新能力的定义者

## 结果与复盘

### 实际案例

大迁徙模型解释和预测了多个商业现象：
- **咖啡市场**：从"第三空间"（星巴克）迁徙到"快取"（瑞幸）再到"精品"（Manner）
- **零售市场**：从"大卖场"迁徙到"电商"再到"即时零售"
- **内容消费**：从"长视频"迁徙到"短视频"再到"直播"
- **工作方式**：从"办公室"迁徙到"远程"再到"混合办公"

### 关键洞察

1. **迁徙是持续的**：不是一次性事件，而是持续的过程
2. **迁徙有层次**：从功能层到情绪层到意义层，层层深入
3. **迁徙可预测**：虽然具体路径不确定，但大方向有规律可循

### 常见误区

1. **把 fad 当 trend**：短期热点不等于长期迁徙
2. **过早布局**：迁徙需要时机，太早成为先烈
3. **忽视存量**：迁徙不是放弃存量，而是找到增量的同时维护存量

## 专家思维还原

> 刘润会如何分析这个案例？

"大迁徙模型的底层逻辑，来自熊彼特的'创造性破坏'理论。经济增长的本质，不是量的积累，而是结构的变迁。旧的结构被破坏，新的结构建立，这就是增长。

从第一性原理来看：
- 需求永远不会消失，只会转移
- 情绪永远不会静止，只会流动
- 能力永远不会停滞，只会进化

所以，增长的关键不是'做得更多'，而是'跟对方向'。

很多企业的问题在于，他们在'需求已经迁走'的地方继续投入。就像河流改道了，你还在旧河道里挖沙。挖得越深，离水越远。

大迁徙模型的三个维度，对应三个问题：
1. 需求迁徙：人们不再想要什么？
2. 情绪迁徙：人们现在在意什么？
3. 能力迁徙：什么新工具可以解决问题？

当你在这三个维度上都找到'迁徙的证据'，就是一个高置信度的机会。"
